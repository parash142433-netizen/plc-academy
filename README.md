# PLC Academy

An offline reader and simulator workbench for studying the PLC / HMI / SCADA tutorials published at
[plc-hmi-scadas.com](https://www.plc-hmi-scadas.com/).

**This repository contains only the application code.** The articles, images and downloads belong to
their original authors (principally Jose Manuel Luque and the other contributors credited on each page)
and are *not* included. You generate a private local copy for personal study with the included crawler;
every mirrored page keeps its author, original URL and a credit line.

## What's here

| Path | Purpose |
|---|---|
| `src/` | Vite + React reader: category tree, Ctrl+K search (Fuse.js), progress, bookmarks, Markdown export |
| `src/sims/` | Three browser simulators: GrafSim (GRAFCET/SFC), thermal PID loop, ISA-88 colour batching |
| `scraper/crawl.mjs` | Playwright + Cheerio + Turndown crawler; honours `robots.txt`, throttled, keeps attribution |
| `scripts/gen-images.mjs` | Draws SVG stand-ins (marked "Generated by Claude") for images missing on the original site |
| `public/assets/generated/` | The generated stand-in SVGs |

## Run it

```bash
npm install
npx playwright install chromium
npm run scrape        # optional: MAX_PAGES=40 npm run scrape for a small test
npm run dev
```

Please be considerate: the crawler is rate-limited by default; do not republish the mirrored content
without permission from its authors.

## Notes

- Simulators are teaching aids, not validated process models.
- Images marked *Claude-generated* are illustrations written by an AI model, not the originals.
