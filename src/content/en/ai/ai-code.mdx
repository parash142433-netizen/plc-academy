# AI-Generated Code

Complete projects where AI writes the code and the human directs. Games, applications and tools created entirely by language models.

How far can a language model go with the right instructions? In this section you will find functional projects — from games to utilities — generated from start to finish with **ChatGPT**, **GitHub Copilot** and **Claude**. The engineer provides the idea and oversight; the AI provides the code.
