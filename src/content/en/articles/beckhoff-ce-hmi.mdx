# Beckhoff - HMI CE

Jose Manuel Luque 31 Jan, 2019

Beckhoff HMI CE SCADA TwinCAT

**Beckhoff - HMI CE**

![](./assets/images/beckhoff-ce-hmi/vba-logo.png) ![](./assets/images/beckhoff-ce-hmi/vba-logo.png) ![](/user_images/vba-logo.png) ![](/user_images/vba-logo.png)

While researching on the BECKHOFF website about the CX1020 device, this is part of the information.

For BECKHOFF embedded products based on the CE operating system, there are different SCADA packages with driver adaptation to the TwinCAT system.

In general, the SCADA CE Run-Time versions require a large memory version.

▪The SCADA CE Run-Time modules can be ordered pre-installed on a BECKHOFF system based on CE. The required SCADA license must be ordered from the SCADA provider.

▪The necessary editors / IDEs for designing the HMI solution must be requested from the corresponding SCADA provider.

For those SCADA applications, a CE-based system with larger memory should be used.

![Claude-generated diagram: Beckhoff CE HMI components](./assets/generated/beckhoff-ce-hmi.svg)

In summary, this means that we will have the Runtime of the SCADA system we have selected installed on the device itself.
