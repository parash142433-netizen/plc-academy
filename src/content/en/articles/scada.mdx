# SCADA — Supervisory Control and Data Acquisition

Programming and configuration guides for the main industrial SCADA systems on the market.

**SCADA (Supervisory Control And Data Acquisition)** systems are the nerve center of industrial supervision. They enable real-time process data acquisition, alarm management, historical data generation, and provide a global view of the plant from one or multiple stations.

Unlike HMIs (machine-oriented), SCADAs are designed to handle large volumes of data, distributed architectures (client/server, redundancy), and connectivity with multiple controllers and protocols.

In this section you will find practical guides for the main systems on the market: **Wonderware/AVEVA** (InTouch, System Platform, ArchestrA, Historian), **Siemens WinCC** (WinCC V7/V8, WinCC RT Professional, WinCC Unified), **Rockwell** (RSView32, FactoryTalk View SE, FactoryTalk Historian), **Schneider** (CitectSCADA, Vijeo Citect), **COPA-DATA Zenon** and others such as FIX32/iFix and TopKapi.

Each article covers driver configuration, communications, scripting (VBScript, ANSI C, VBA, Cicode), databases, ActiveX/.Net controls, user management, WebNavigator, redundancy and much more.

### [Wonderware / AVEVA](#/a/en%2Fscada-intouch)

Wonderware was the leading name in industrial SCADA. Today, following the acquisition of **Invensys** by **Schneider Electric**, the commercial brand is **AVEVA**.

**InTouch** — the most widely used SCADA in industry. The latest available version is **InTouch 2017 Update 3**. For distributed projects with an object-oriented model, **System Platform / ArchestrA** is used.

**InTouch Machine Edition** (formerly **InduSoft**) is the machine-oriented version, currently known as **AVEVA Edge HMI**.

**CitectSCADA** — following Schneider's acquisition of Citect, it was renamed CitectSCADA. The latest available version is **CitectSCADA 2018**.

Schneider also maintained its own solutions: **Monitor Pro**, **Vijeo Look**, **Vijeo Citect** (same as CitectSCADA but with the Schneider name; no updates since 2015), **PowerScada**, **ClearScada**, and **EcoStruxure Machine SCADA Expert** (formerly Vijeo XL).

### [Simatic Siemens](#/a/en%2Fscada-siemens)

### [Allen Bradley / Rockwell](#/a/en%2Fscada-allen-bradley)

Rockwell Automation SCADA systems have evolved from **RSView32** to **FactoryTalk View SE**.

**RSView32** — Rockwell's classic SCADA platform, whose last version was **RSView32 V7.60**.

**FactoryTalk View Site Edition (SE)** — the successor to RSView32 for distributed client/server architectures. The latest available version is **FactoryTalk View SE V10.0**.

### [Schneider SCADA](#/a/en%2Fscada-schneider)
