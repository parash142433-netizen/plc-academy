# S7-1500 OPC UA Client(&quot;The security checks failed using the selected certificates&quot;)

Jose Manuel Luque 26 May, 2019

S7-1500 OPC UA

**S7-1500 OPC UA Client**("The security checks failed using the selected certificates")

![](./assets/images/tia-portal-s71500-client-opc-ua/vba-logo.png) ![](./assets/images/tia-portal-s71500-client-opc-ua/vba-logo.png) ![](/user_images/vba-logo.png) ![](/user_images/vba-logo.png)

"**The security checks failed using the selected certificates**"

If you are configuring an OPC UA Client instance with TIA Portal v15.1, and when trying to connect Online with the configuration without security (No Security)

![](./assets/images/tia-portal-s71500-client-opc-ua/S71500_OPCUA_Client_006.png)

A pop-up window will appear with the name of the Server you are configuring, and you confirm to trust the indicated certificate

![](./assets/images/tia-portal-s71500-client-opc-ua/S71500_OPCUA_Client_007.png)

It does not connect and the error "The security checks failed using the selected certificates" appears

**Solution**: Install the latest update, at the time of performing these tests, the current update is 1. Once installed, follow the same steps and it works correctly.

![](./assets/images/tia-portal-s71500-client-opc-ua/S71500_OPCUA_Client_008.png)
