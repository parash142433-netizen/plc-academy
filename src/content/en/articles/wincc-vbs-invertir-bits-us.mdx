Jose Manuel Luque

WinCC VBScript InvertBitInTag

**WinCC VBScript InvertBitInTag**

We've already seen the [Set and Reset function of a bit](#/a/en%2Fwincc-funcion-activar-desactivar-bits). The next function is inverting a bit of a Variable. I have created the two versions that are possible, the one we write directly to the variable or the one we write in the DataManager, if you have doubts, please check this [explanation](#/a/en%2Fwincc-rw-tag).

What we do is consult the bit that we pass through parameter and depending on how it is, we invert it.

As we have seen before, we use the And and Or functions.
