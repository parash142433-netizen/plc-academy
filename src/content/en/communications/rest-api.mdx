# REST API

Integration of industrial systems with web services through RESTful APIs.

REST APIs (Representational State Transfer) allow industrial automation systems to communicate with web applications, dashboards, databases and cloud services in a standard and secure way.

Increasingly, manufacturers offer REST interfaces in their products: WinCC Unified (GraphQL/REST), FactoryTalk Optix, AVEVA System Platform, and tools like Node-RED or Flask allow creating custom APIs to expose process data.
