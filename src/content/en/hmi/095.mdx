# Comfort Panels control Media Player

Jose Manuel Luque

Comfort Panels control Media Player

**Comfort Panels control Media Player**

The new generation of panels, the Comfort Panels, all have the Media Player Object available for playing video or audio files, which in turn does not allow for simulation.

![](./assets/images/095/WinCC-Advanced-Media-Player-04.png)

However, if we want to use the Media Player in WinCC RT Advanced, it is not available, which is not a problem since we can execute it with the StartProgram function, passing the path of our video or audio file as parameters.

![](./assets/images/095/WinCC-Advanced-Media-Player-05.png)

A small demonstration video, where the video of the Diagnostic Viewer System object is displayed.
