Articles on configuring PanelView panels with PanelBuilder32 and FactoryTalk View ME.

**Allen Bradley PanelView** displays are the HMI standard in Rockwell controller installations. The software has evolved from **PanelBuilder32** (for PanelView 300/550/900/1000) to **FactoryTalk View Machine Edition** (for PanelView Plus and Plus 7).

**PanelBuilder32** (V3.82) is dedicated software for the original PanelView panels, with DH485, DH+ and DF1 communication. **FactoryTalk View ME** extends capabilities with EtherNet/IP, RSLinx Enterprise, macros, Data Logs, alarms, user security and ActiveX controls. It also allows simulation on PC with RSLogix Emulate 5000.

Here you will find everything from basic communication setup and project backup, to advanced examples of Data Logs, alarms, PlaceHolders, language switching, and firmware updates on PanelView Plus.
