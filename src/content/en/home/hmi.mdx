# HMI — Human Machine Interface

Programming and configuration guides for HMI panels from the main automation manufacturers.

**HMI (Human Machine Interface)** panels are the visual bridge between the operator and the industrial process. From early alphanumeric terminals to modern full-color touchscreens, HMIs enable supervisory control, monitoring, and diagnostics for any automation system.

In this section we cover the configuration and programming of the panels we have the most experience with: **Siemens** (ProTool, WinCC Flexible, WinCC in TIA Portal for OP, TP, MP, KTP and Comfort panels), **Rockwell Allen Bradley** (PanelBuilder32 and FactoryTalk View ME for PanelView and PanelView Plus), **Schneider** (XBT-L1000 and Vijeo Designer for Magelis panels), and **Omron** (NB-Designer for NB series).

Each guide covers practical aspects: project transfer, PLC communication configuration, user management and security, scripting (VBScript, macros), recipes, alarms, ActiveX controls and much more. We also include answers to questions submitted by our readers.

### [Siemens Simatic](#/a/en%2Fhmi-siemens)

Within the Simatic family, we divide the panels by their programming software in chronological order.

**Comtext**, the legacy software installed as an additional package within Step 5; some of the TD Text Displays programmed with it included the TD10, and OPs such as the OP5, OP15, OP20.

**ProTool** replaced its predecessor Comtext. When migrating a Comtext project to ProTool for the new generation of TD/OP, the KONVERT application was required. The last version of ProTool was **V6.0 SP2**.

**WinCC Flexible** was first released in 2004 and replaced ProTool for the new generation of OP/TP/MP panels. Migration from ProTool to WinCC Flexible is performed within WinCC Flexible itself. The last version was **WinCC Flexible 2008 SP3**.

**TIA Portal** (Totally Integrated Automation) represents the new concept: integrating all programming tools within a single software. TIA Portal includes **WinCC RT Professional** (equivalent to the WinCC SCADA) and **WinCC RT Advanced** (equivalent to WinCC Flexible Runtime PC).

### [Allen Bradley Rockwell](#/a/en%2Fhmi-allen-bradley)

Within the Allen Bradley (Rockwell Automation) family, we divide the panels by their programming software. Except for the MDPS, **RSLinx** software is required to establish communication with the PanelView.

**MicroView MDPS** for programming the legacy DTAM (Micro Operator Interface Module).

**PanelBuilder 32** — software for programming PanelView panels. The last available version was **PanelBuilder32 V3.82**.

**FactoryTalk View Machine Edition** — software for the new generation of **PanelView Plus** and **PanelView Plus V6.0**; the latest available version is FactoryTalk View V8.0.

### [Schneider Telemecanique](#/a/en%2Fhmi-schneider)

For programming Schneider Telemecanique HMIs, we use the following software, which varies depending on the model and age.

**XBT-L1000** — software for programming legacy panels that are still in use, whether for modifications or programming of older panels. For migration from XBT-L1000 to Vijeo Designer, an application called **Switch From XBTL1000 2 Vijeo** is available.

**Vijeo Designer** — current software for programming **Magelis STO, STU, XBT-XX, Smart iPC, and Compact iPC** models. The latest available version is **Vijeo Designer V6.2**.
