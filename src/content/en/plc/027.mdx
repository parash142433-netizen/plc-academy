# Configuration of the Ethernet Devices Driver

Jose Manuel Luque

RSLinx Ethernet Devices Drivers

In this practice, we will see how to configure the Ethernet Devices Driver, whether for programming a PLC or an HMI as in the following example. As in previous practices, the first step is to run RSLinx and add a new Driver.

![](./assets/images/027/RSLinx%20Ethernet%20Devices%20-01.jpg)

2.- To access the PLC or HMI with an Ethernet port, RSLinx has two drivers as shown in the following image; I will use the previously mentioned Ethernet devices.

![](./assets/images/027/RSLinx%20Ethernet%20Devices%20-02.jpg)

3.- We give it a name that interests us and press OK! It will automatically be added to the list of configured drivers with a running status.

![](./assets/images/027/RSLinx%20Ethernet%20Devices%20-03.jpg)

4.- In the following image, we need to know the IPs of the devices we are going to add, so all devices must be on the same network.

![](./assets/images/027/RSLinx%20Ethernet%20Devices%20-04.jpg)

5.- We can now see that the PLC has been detected, an SLC 5/05, the only one in its family that has an Ethernet port, a Panel View Plus, and the PC itself. With this, we are ready to transfer the project to the PLC with RSLogix500 or to the Panel View Plus 600 with Factory Talk View ME.  
  

![](./assets/images/027/RSLinx%20Ethernet%20Devices%20-05.jpg)
