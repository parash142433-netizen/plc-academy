# CX-Simulator

Jose Manuel Luque

CX-Simulator CX-One Omron Controllers PLC

In this first practice, I will configure the CX-Simulator to check our program in the CX-Programmer.

1.- We run the CX-Simulator and create a new PLC with the wizard, specifying the directory where the necessary files will be created

![](./assets/images/036/CX-Simulator01.jpg)

![](./assets/images/036/CX-Simulator02.jpg)

2.- The next step is to select the type of CPU; I have selected a CJ1M-CPU23.

![](./assets/images/036/CX-Simulator03.jpg)

3.- The next step is to select the modules that our PLC will have; we can select from the different types and add them according to our needs by clicking on the << icon to add and >> to remove.

![](./assets/images/036/CX-Simulator04.jpg)

![](./assets/images/036/CX-Simulator05.jpg)

![](./assets/images/036/CX-Simulator08.jpg)

4.- Once all modules have been added, we continue with the wizard by clicking next.

![](./assets/images/036/CX-Simulator10.jpg)

5.- The following screens can have their values left as default; for simulation operation, it is not necessary to modify them.

![](./assets/images/036/CX-Simulator11.jpg)

![](./assets/images/036/CX-Simulator12.jpg)

![](./assets/images/036/CX-Simulator13.jpg)

6.- With these steps, we have finished configuring the virtual PLC; now we click on Connect and it will be ready to operate.

![](./assets/images/036/CX-Simulator14.jpg)

7.- Now we open our project in CX-Programmer or create a new one; if we create a new one, select the same CPU that was used when creating the Virtual PLC and in the network type, click on configuration to set the same parameters as those in the Simulator.

![](./assets/images/036/CX-Simulator15.jpg)

![](./assets/images/036/CX-Simulator16.jpg)

8.- Once opened, to start the simulation, we go to the simulation tab and click on connect with Online Simulator and the PLC goes into Run mode.

![](./assets/images/036/CX-Simulator18.jpg)

9.- We can now check our project, force variables, observe the program, etc...

![](./assets/images/036/CX-Simulator19.jpg)
