# Remote Device Linx Gateway

Remote access to RSLogix Emulate 5000 using RSLinx Gateway.

Jose Manuel Luque Feb 13, 2013

RSLinxGatewayRSLogix Emulate 5000Rockwell

![Remote Device Linx Gateway](./assets/images/075/RSLinx%20Gateway%2001.png)

**Objective**

This practice configures the Remote Device Linx Gateway driver. Requirements are RSLinx Gateway and both computers being in the same workgroup.

The goal is to access devices available on another PC acting as a gateway, specifically RSLogix Emulate 5000, to later use it with FactoryTalk View ME.

![Environment with RSLinx Gateway](./assets/images/075/RSLinx%20Gateway%2001.png)

![Computers in the same workgroup](./assets/images/075/RSLinx%20Gateway%2005.png)

**Enable RSLinx Classic Gateway**

To enable the gateway function, go to Communications > Configure Gateway and select Enable RSLinx Classic Gateway.

In Client Access List, add the IP of the computer from which the Remote Device Linx Gateway driver will be configured.

![RSLinx Classic Gateway enabled](./assets/images/075/RSLinx%20Gateway%2007.png)

![Client access list in RSLinx Gateway](./assets/images/075/RSLinx%20Gateway%2008.png)

**Check the Gateway Computer**

The next image shows RSLogix Emulate 5000, the computers in the same workgroup and the computer IP address.

![RSLogix Emulate 5000 visible on the gateway computer](./assets/images/075/RSLinx%20Gateway%2011.png)

![IP and workgroup computers](./assets/images/075/RSLinx%20Gateway%2009.png)

**Create the Remote Driver**

Now go to the computer where the driver will be configured, where FactoryTalk View Machine Edition is installed to simulate a PanelView.

Add a new driver and choose Remote Device Linx Gateway. Assign a name and enter the IP address of the computer where the driver to access is located.

![Adding a new driver in RSLinx](./assets/images/075/RSLinx%20Gateway%20-02.png)

![Remote Device Linx Gateway driver selection](./assets/images/075/RSLinx%20Gateway%20-03.png)

![Gateway computer IP for the remote driver](./assets/images/075/RSLinx%20Gateway%20-04.png)

**Verify Remote Access**

If everything is correct, the driver is running and remote access to RSLogix Emulate 5000 is available.

After that, only a new topic for that controller needs to be configured, as used in the FactoryTalk View ME practice.

![Remote Device Linx Gateway driver running](./assets/images/075/RSLinx%20Gateway%20-05.png)

![Remote access to RSLogix Emulate 5000](./assets/images/075/RSLinx%20Gateway%20-07.png)
