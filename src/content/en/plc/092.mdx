# Update Firmware on a ControlLogix

Jose Manuel Luque

RSLogix 5000 Firmware ControlLogix

In today's practice, we will see how to update the firmware of a ControlLogix. Once we have RSLogix 5000 open, we have a shortcut to the ControlFLASH application in the tools menu.

Once opened, this is the interface shown to us with the wizard. We click next.

![](./assets/images/092/ABControlFlash-00.png)

![](./assets/images/092/ABControlFlash-01.png)

The first step is to choose the reference number of our ControlLogix. Once selected, we click next and look for our device according to the driver we have configured for it. In this case, it is a serial communication with the DF1 driver; you can find its configuration here.

![](./assets/images/092/ABControlFlash-02.png)

![](./assets/images/092/ABControlFlash-03.png)

Once selected, it will show us the current version and the new one that will be installed. If we agree, we can confirm.

![](./assets/images/092/ABControlFlash-04.png)

![](./assets/images/092/ABControlFlash-05.png)

Once we have confirmed to finish, it will show us another pop-up window asking if we want to load it to the device. We accept, and the process begins.

![](./assets/images/092/ABControlFlash-06.png)

![](./assets/images/092/ABControlFlash-07.png)

A progress bar will show us the status of the update.

![](./assets/images/092/ABControlFlash-09.png)

![](./assets/images/092/ABControlFlash-08.png)

Once completed, it will show us the following window, and the firmware has been updated correctly.

![](./assets/images/092/ABControlFlash-10.png)
