# Enable Source Protection

Jose Manuel Luque

Studio 5000 Protection RSLogix5000

**Enable Source Protection**

If you are using a version prior to Studio5000 v31 by default and need to configure or modify a program that has some function, AddOn, etc. protected, and your version does not have the option "Configure Source Protection" enabled

![](./assets/images/ab-source-protection/AB_SourceProtection_01.png)

In the Installation DVD, in the Tools Directory, you will find the installer for the Plugin and documentation (Source Protection Tool)

![](./assets/images/ab-source-protection/AB_SourceProtection_03.png)

We proceed with the installation confirming that we want to add the option to enable it.

![](./assets/images/ab-source-protection/AB_SourceProtection_04.png)

When we start our Studio 5000, the option is now available.

![](./assets/images/ab-source-protection/AB_SourceProtection_05.png)

Starting from RSLogix Studio 5000 v31, this option is enabled by default along with new security features.

![](./assets/images/ab-source-protection/AB_SourceProtection_06.png)
