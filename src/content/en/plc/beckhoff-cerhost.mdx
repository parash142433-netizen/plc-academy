# Beckhoff CERHOST

Jose Manuel Luque 31 Jan, 2019

Beckhoff CERHOST

**Beckhoff CERHOST**

Continuing with the CX1020, we will look at the Beckhoff CERHOST utility to connect remotely and manage the system. It can be downloaded from [Beckhoff](https://infosys.beckhoff.com/english.php?content=../content/1033/sw_os/2018363019.html&id=)

![](./assets/images/beckhoff-cerhost/TwinCAT_CERHOST_01.png)

Once downloaded, we start it and connect, we log in with the credentials and that's it

![](./assets/images/beckhoff-cerhost/TwinCAT_CERHOST_02.png) ![](./assets/images/beckhoff-cerhost/TwinCAT_CERHOST_03.png)

We are now connected, and from now on we manage our system

![](./assets/images/beckhoff-cerhost/WindowCE_Install_Server_19.png)

Start -> Control Panel:

![](./assets/images/beckhoff-cerhost/TwinCAT_CERHOST_05.png)

CX Configurator, for example, we are going to enable the FTP service, disable it, manage users, etc...

![](./assets/images/beckhoff-cerhost/TwinCAT_CERHOST_06.png)

Change IP address ...

Depending on the changes we make, we need to restart the device and we do this with Start -> Reset

![](./assets/images/beckhoff-cerhost/TwinCAT_CERHOST_07.png)
