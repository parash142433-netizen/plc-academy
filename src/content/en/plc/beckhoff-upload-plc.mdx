# Upload PLC TwinCAT Project

Jose Manuel Luque 16 May, 2019

Upload TwinCAT PLC

**Upload PLC TwinCAT Project**

We have just seen how we [downloaded the hardware configuration](#/a/en%2Fbeckhoff-upload-config), now we are going to download the PLC project.

We run the TwinCAT PLC Control, and simply select Open

![](./assets/images/beckhoff-upload-plc/TwinCAT_Config_29.png)

Here we can open a project that we already have stored in our directory X, or open the project directly from the PLC, for this we select the PLC button

![](./assets/images/beckhoff-upload-plc/TwinCAT_Config_30.png)

A pop-up window will appear to select the type, in my case PC or CX (x86) and we confirm with OK

![](./assets/images/beckhoff-upload-plc/TwinCAT_Config_31.png)

Now we are going to select our Target, our PLC and select Run-Time 1, as seen in the following image.

![](./assets/images/beckhoff-upload-plc/TwinCAT_Config_32.png)

If we have previously downloaded any project and have libraries in our directory, we may see a warning like the following.

![](./assets/images/beckhoff-upload-plc/TwinCAT_Config_33.png)

Once downloaded, we can save it with the name that interests us. And note how we are connected to our PLC 192.168.1.250

![](./assets/images/beckhoff-upload-plc/TwinCAT_Config_34.png)
