# FactoryTalk Echo - Update firmware v.37

Jose Manuel Luque 27 Oct, 2024

PLC ROCKWELL PLC ROCKWELL PLC

![FactoryTalk Echo - Update firmware v.37](./assets/images/blog-factorytalk-echo-update-firmware-v-37/FTecho_4.png)

If you already had your FactoryTalk Echo to work with the firmware of the latest version v.37, you need to update it.  
Do you want to know what has been implemented in this new release of Studio 5000 v.37? Here you have the [table](https://www.rockwellautomation.com/en-us/products/software/factorytalk/version-history.html) of the main changes.

![](./assets/images/blog-factorytalk-echo-update-firmware-v-37/FTecho_1.png)

  
On the [Rockwell Automation](https://compatibility.rockwellautomation.com/pages/Home.aspx) page, you can search by Firmware ...

![](./assets/images/blog-factorytalk-echo-update-firmware-v-37/FTecho_2.png)

  
We download the firmware that interests us and install it on our machine.

![](./assets/images/blog-factorytalk-echo-update-firmware-v-37/FTecho_4.png)

  
We have now updated our FactoryTalk Echo.

![](./assets/images/blog-factorytalk-echo-update-firmware-v-37/FTecho_5.png)

  
And we can now simulate with version v.37.

![](./assets/images/blog-factorytalk-echo-update-firmware-v-37/FTecho_6.png)
