![RSLogix 5000 - Studio 5000 - Electronic Data Sheet (EDS)](./assets/images/blog-rslogix-5000-studio-5000-electronic-data-sheet-eds/Prosoft_PLX30-5.png)

What is the [EDS](https://www.rockwellautomation.com/es-es/support/documentation/electronic-datasheets.html)? It is a text file that contains detailed information about a network device, such as a sensor, a controller, or an actuator. In the context of industrial networks and control systems, the EDS is used to define the characteristics of the device, such as its configuration parameters, data types, and communication functions.  
  
Now that we know what it is and what it is used for, let's see how to register these files for our working environment in RSLogix 5000 / Studio 5000 and subsequently configure our network.  
  
For the following example, I have downloaded from Prosoft the gateway [PLX30](https://www.prosoft-technology.com/Products/Gateways/PLX3x/PLX31/EtherNet-IP-to-Siemens-Industrial-Ethernet)
