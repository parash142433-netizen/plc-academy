# Syswin 3.4 Upload Backup of the Project

Jose Manuel Luque

Syswin 3.4 Omron CX-Programmer

**Syswin 3.4 Upload Backup of the Project**

We need to modify a machine that has an Omron PLC from the CQM1 series, and the first thing we need to do is download the project for that modification. For this practice, we will use the Syswin 3.4 software, although we can also use the CX-Programmer, but this is the one we will use.

![](./assets/images/omron-syswin/Syswin_02.png)

The first thing we do is create a new project.

![](./assets/images/omron-syswin/Syswin_03.png)

We define the type, model, CPU, etc...

![](./assets/images/omron-syswin/Syswin_04.png)

Once the project is created, we can access Project - Communications...

![](./assets/images/omron-syswin/Syswin_05.png)

We define the parameters of our serial communication, by default they are as follows.

![](./assets/images/omron-syswin/Syswin_06.png)

And finally, we go to Online - Upload program from PLC...

![](./assets/images/omron-syswin/Syswin_07.png)

We select and confirm...

![](./assets/images/omron-syswin/Syswin_08.png)

We now have our project, now we just need to modify the sequence, and reload it, and that's it.

![](./assets/images/omron-syswin/Syswin_09.png)
