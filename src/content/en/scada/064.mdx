# ArchestrA, Importing .Net Controls

Jose Manuel Luque

ArchestrA Intouch Wonderware Scada

As I mentioned in previous practices, ArchestrA is based on object-oriented programming (OOP). In today's practice, we will import Microsoft .Net objects into our project, allowing us to use all of them.

The first thing we will do is create a new toolset, a folder within the Graphic directory where we will insert all the imported controls.

![](./assets/images/064/ArchestrA%20DotNet%20-00.png)

![](./assets/images/064/ArchestrA%20DotNet%20-01.png)

Once the toolset (folder) is created, although it is not necessary, we select Galaxy -> Import -> Client Control to import the objects

![](./assets/images/064/ArchestrA%20DotNet%20-02.png)

![](./assets/images/064/ArchestrA%20DotNet%20-03.png)

The directory we need to select is the following:

![](./assets/images/064/ArchestrA%20DotNet%20-06.png)

A pop-up window appears, and we must select the desired option

![](./assets/images/064/ArchestrA%20DotNet%20-05.png)

The import of objects begins, with a total of 51 objects, which are the same as when we worked with Visual Basic .Net

![](./assets/images/064/ArchestrA%20DotNet%20-07.png)

![](./assets/images/064/ArchestrA%20DotNet%20-08.png)

We can now move the objects within the created folder, and from this moment on, we can use them for the creation of new symbols.

![](./assets/images/064/ArchestrA%20DotNet%20-09.png)
