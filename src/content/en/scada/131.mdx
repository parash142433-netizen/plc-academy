# Introduction to Wonderware Information Server

Jose Manuel Luque

Introduction to Wonderware Information Server

**Introduction to Wonderware Information Server  
**

Within all Wonderware applications, there is the Information Server, this is the additional software that needs to be installed when we want to create a Web Server for our application developed in Intouch.

Once installed, we can access it from start->All Programs ->Wonderware->Information Server ->Home, and the following screen will open for its administration.

The following animation shows all the directories that we can configure, _Application Manager_ corresponds to the application that we are going to distribute. _User Manager_, user management. _License Manager_ License status and expiration date. _Portal Configuration_ Environment configuration. _Data Source Manager_ Database management _Factory Alarm Manager_ Manage the alarms that we have previously configured in a database. In addition to the documentation, the most important is Win-XML Exporter, which is the application we will use to convert and publish our application.

                        [![Get Adobe Flash player](./assets/images/131/get_flash_player.gif)](http://www.adobe.com/go/getflash)

In the next practice, once Win-XML is installed, we will convert and publish an Intouch application to add it to our Web Server.
