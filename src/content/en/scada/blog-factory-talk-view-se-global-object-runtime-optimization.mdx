# Factory Talk View SE - Global Object Runtime Optimization

Jose Manuel Luque March 30, 2024

Factory Talk VIEW SE Factory Talk View SE SCADA SCADA

![Factory Talk View SE - Global Object Runtime Optimization](./assets/images/blog-factory-talk-view-se-global-object-runtime-optimization/FTViewSE_GlobalOpt-3.png)

Are you working with Global Objects? Do you have a distributed architecture? Are you familiar with the Global Object Runtime Optimization functionality?  
If you do not have the Global Object Runtime Optimization functionality enabled, you need to enable it to improve the performance of your application.

![](./assets/images/blog-factory-talk-view-se-global-object-runtime-optimization/FTViewSE_GlobalOpt-1-1024x510.png)

To enable it, you must select the checkbox located here:  
**Tools** -> **Options** -> **Global Objects**

![](./assets/images/blog-factory-talk-view-se-global-object-runtime-optimization/FTViewSE_GlobalOpt-4-1024x510.png)

We enable the checkbox and apply by clicking the **Compile Global Objects** button.

![](./assets/images/blog-factory-talk-view-se-global-object-runtime-optimization/FTViewSE_GlobalOpt-3-1024x509.png)

When compiling, within the directory of our main project, there is the RuntimeGfx directory where a copy of the screens is created.

![](./assets/images/blog-factory-talk-view-se-global-object-runtime-optimization/FTViewSE_GlobalOpt-2-1024x507.png)
