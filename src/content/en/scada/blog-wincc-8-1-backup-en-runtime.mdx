# WinCC 8.1 Backup in Runtime

Jose Manuel Luque Mar 29, 2025

SCADA WinCC WinCC

![WinCC 8.1 Backup in Runtime](./assets/images/blog-wincc-8-1-backup-en-runtime/image-42.png)

This new feature of version **WinCC 8.1** deserves a **article** :-)  
  
Ten years ago, I wrote this [post](https://plc-hmi-scadas.com/WinCC_Backup_WinCCRuntime.php) to implement this functionality... Of course, it had a lot to improve, but on more than one occasion it fulfilled its purpose ;-)  
That said, you should know that with the application **CCStartStop** this functionality is included.

What functionalities does this application offer:

Code

```
CCStartStop.exe /?
```

![](./assets/images/blog-wincc-8-1-backup-en-runtime/WinCCBackupOnline-5-1024x638.png)

  
Compared to the previous version **WinCC V8.0,** where we already had some functionalities :-)

![](./assets/images/blog-wincc-8-1-backup-en-runtime/image-41.png)

  
Executed without arguments, it returns project information.

![](./assets/images/blog-wincc-8-1-backup-en-runtime/WinCCBackupOnline-6.png)

  
And to perform the backup while in Runtime.

Code

```
CCStartStop.exe /b /to:C:\Backups
```

![](./assets/images/blog-wincc-8-1-backup-en-runtime/image-42.png)

  
And here is our online backup, where it is clear that what it does is a backup of the databases, so that the runtime does not have to be stopped :-)

![](./assets/images/blog-wincc-8-1-backup-en-runtime/2025-03-29-16_30_42-PHSTraining.png)
