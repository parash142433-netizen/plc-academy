# WinCC 8.1 News

Jose Manuel Luque Nov 17, 2024

SCADA SCADA WinCC WinCC

![WinCC 8.1 News](./assets/images/blog-wincc-8-1-novedades/WinCC-8.1.png)

We now have the new version of [WinCC 8.1](https://support.industry.siemens.com/cs/document/109976749/wincc-v8-1-general-information-and-installation?dti=0&lc=en-ES) and here are some of the new features ...  
The new WinCC now comes with [SQL Server 2022](https://www.microsoft.com/es-es/sql-server/sql-server-2022) and is released for the following operating systems:

*   Windows 10
*   Windows 11
*   Windows Server 2019
*   Windows Server 2022

WebNavigator / WebUx / OPC UA Server / IT Connector as optional when running Runtime.

![](./assets/images/blog-wincc-8-1-novedades/image-8.png)

####   
New unlimited tags license and unlimited Web clients

![](./assets/images/blog-wincc-8-1-novedades/image-1.png)

####   
Enhancing security measures

*   RFID - Login method
*   MOBILEAUTH - I haven't found more information?
*   LOCK USER - User lock upon authentication failure

![](./assets/images/blog-wincc-8-1-novedades/image-2.png)

  
New tool to verify if changes have occurred in the WinCC installation

![](./assets/images/blog-wincc-8-1-novedades/image-3.png)

####   
Enhancing diagnostics and analysis

*   New system tags for VBScript
*   In multi-projects, the system variable ConnectedRTClients indicates the number of clients connected in runtime
*   New functions for diagnosing OPC UA Server/Client

![](./assets/images/blog-wincc-8-1-novedades/image-4.png)

####   
Enhancing communication functionalities

*   Multi-instance of communication drivers is allowed, enabling multiple processes for communications, which will increase performance.

![](./assets/images/blog-wincc-8-1-novedades/image-5.png)

####   
Enhancing functionalities in Runtime

*   New **Maintenance Stop** state.  
    Allows stopping the runtime without disconnecting all segments, only the active ones :-)

![](./assets/images/blog-wincc-8-1-novedades/image-6.png)

####   
Enhancing functionalities in development (Graphics Designer)

*   New predefined designs (WinCC Neo xxx)
*   Dynamic SVG dynamization (Script / Properties)

####   
Enhancing functionalities in Alarms / Events

*   New Alarm Channel driver, to filter and identify states of our plant
*   User identification for Lock/Unlock - Hide/Unhide - Acknowledge  
    ( No need to configure an extra column with @CurrentUser anymore ;-) )

![](./assets/images/blog-wincc-8-1-novedades/image-7.png)

Now waiting for Siemens to make the presentation ... ;-)
