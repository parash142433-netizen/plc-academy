# WinCC - WebNavigator "Failed to load https://Sever:4430/Main.PD\_"

Jose Manuel Luque 22 Sep, 2024

SCADA SCADA WinCC WinCC

![WinCC - WebNavigator ](./assets/images/blog-wincc-webnavigaror-failed-to-load-https-sever4430-main-pd/WebNavigatorError-2.png)

If after correctly configuring our WebNavigator, publishing the content, and there are no errors, you receive the following message

![](./assets/images/blog-wincc-webnavigaror-failed-to-load-https-sever4430-main-pd/WebNavigatorError-1.png)

  
To solve it, you need to uncheck the checkbox for [internet options](https://support.microsoft.com/es-es/topic/al-hacer-clic-en-opciones-de-internet-en-el-men%C3%BA-herramientas-aparece-un-mensaje-de-error-61fd0f74-bbff-a941-1c45-8101870a2440) -> Advanced -> Security -> **Do not save encrypted pages to disk**

![](./assets/images/blog-wincc-webnavigaror-failed-to-load-https-sever4430-main-pd/WebNavigatorError-2.png)

  
And problem solved :-)

![](./assets/images/blog-wincc-webnavigaror-failed-to-load-https-sever4430-main-pd/WinCC-WebNavigator-HTTPS-Certificate-9.png)
