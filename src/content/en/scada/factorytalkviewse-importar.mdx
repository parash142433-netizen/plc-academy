# Import Factory Talk View SE Project

Jose Manuel Luque

Import Factory Talk View SE Project

**Import Factory Talk View SE Project  
**

The following practice shows how to import a project from Factory Talk View SE, whether we are moving it from the directory where the project is located to another PC for editing, or how to proceed.

We start from the assumption that we have brought a project and it is in a specific directory; the first thing we do is once Factory Talk View Studio is started.

![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_00.png)

Create a new project and select the Import button.

![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_02.png)

We have a pop-up window with a notice; we confirm and follow the wizard, where we select the type of project we have, in our case the selected one.

![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_03.png) ![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_04.png) ![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_05.png)

We look for the directory where our project is located and select the project file \*.sed.

We finish the wizard and if everything is correct, the project loads; there is usually a warning when we work with ActiveX controls that we had on the source PC and are missing on the current one.

![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_06.png)

We can now see our project, edit it, modify it, etc...

![](./assets/images/factorytalkviewse-importar/FactoryTalkViewSE_08.png)
