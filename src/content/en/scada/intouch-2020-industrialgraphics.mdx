# AVEVA Intouch 2020 Import Industrial Graphics

Jose Manuel Luque 14 May, 2020

Intouch 2020 Industrial Graphics

**AVEVA Intouch 2020 Import Industrial Graphics**

![](./assets/images/intouch-2020-industrialgraphics/vba-logo.png) ![](./assets/images/intouch-2020-industrialgraphics/vba-logo.png) ![](/user_images/vba-logo.png) ![](/user_images/vba-logo.png)

When we start our Intouch, by default in the Industrial Graphic toolbox, the predefined symbols do not appear.

All we have to do is right-click on the main menu.

![](./assets/images/intouch-2020-industrialgraphics/Intouch_2020_Industrial_Grap_1.png)

Import Industrial Graphic Library, and the import process begins.

![](./assets/images/intouch-2020-industrialgraphics/Intouch_2020_Industrial_Grap_2.png)

After a few seconds, we now have the two directories with all the symbols.

\-Industrial Graphic Library

\-Situation Awareness Library
