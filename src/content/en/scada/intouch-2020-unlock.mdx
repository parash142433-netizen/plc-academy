# AVEVA Intouch 2020 Unlock application

Jose Manuel Luque 14 May, 2020

The same application is being edited in another session. Cannot edit this application

**AVEVA Intouch 2020 Unlock application**

![](./assets/images/intouch-2020-unlock/vba-logo.png) ![](./assets/images/intouch-2020-unlock/vba-logo.png) ![](/user_images/vba-logo.png) ![](/user_images/vba-logo.png)

If you have worked with Intouch, I am sure you know what the message refers to, _**The same application is being edited in another session. Cannot edit this application**_.

![](./assets/images/intouch-2020-unlock/Intouch_2020_Lock_1.png)

The new version Intouch 2020 has a fabulous button with a lock, which is used to unlock the application.

![](./assets/images/intouch-2020-unlock/Intouch_2020_Lock_2.png)

And if you do not know what that button does or you are using another version and find yourself in this situation, what you need to do is delete the appedit.lok file from the application directory.

![](./assets/images/intouch-2020-unlock/Intouch_2020_Lock_3.png)

If we click the button, we see that it deletes that file and we can now edit our application.

![](./assets/images/intouch-2020-unlock/Intouch_2020_Lock_4.png)
