Once we have downloaded the package of interest from [Oracle](https://www.oracle.com/search/results?Nty=1&Ntk=SI-ALL5&Ntt=ODAC), we start the installation and select the languages we are interested in.

![](./assets/images/oracle-drivers/ODAC_Oracle_01.png)

By default, with the logged-in user who is an administrator.

![](./assets/images/oracle-drivers/ODAC_Oracle_02.png)

We leave the directory by default.

![](./assets/images/oracle-drivers/ODAC_Oracle_03.png)

And here is the list of drivers that will be installed.

![](./assets/images/oracle-drivers/ODAC_Oracle_04.png)

This part is important because with these parameters the TNSNAME.ORA file will be created, which we will use to establish the connection in VBScript. By default, the port is 1521, and unless we have changed the Service Name during installation, it is also ORCL. The PC where it is installed is called DBORACLE or its IP address, and so on...

![](./assets/images/oracle-drivers/ODAC_Oracle_05.png)

![](./assets/images/oracle-drivers/ODAC_Oracle_06.png)
