# Tag Monitor Configuration

Jose Manuel Luque

RSView32 Tag Monitor Configuration

**Tag Monitor Configuration  
**

Once we have [Configured the Tags](#/a/en%2Frsview-tagdatabase), we can set up a window to Monitor the Tags, this is the utility of Tag Monitor, to insert the tags we have created to check their value and status.

Following the previous example, we will Monitor the InternalTag and ExternalTag.

![](./assets/images/rsview-monitortag/RSView32-TagDatabase-11.png)

We just need to insert the name of the Tag in the Table and the values will automatically update if its status is correct, as seen in the following image. Once all Tags are inserted, we save the table and that's it.

![](./assets/images/rsview-monitortag/RSView32-TagDatabase-12.png)
