# RSView32, Scan Class Configuration

Jose Manuel Luque

RSView32 Scan Class Configuration

**Scan Class Configuration  
**

![](./assets/images/rsview-scanclass/RSView32-ScanClass-08.png)

Within the System directory, we find Scan Class, where we will configure the update time of the Tags we create.

The number of possible configurations ranges from A to K, and within each of them, we will configure the ForeGround time and BackGround time.

As we have seen previously, we have 3 options to configure communication with the Controller, whether Direct Driver, OPC Server, or DDE Server.

System -> Scan Class is directly related to the Direct Driver configuration, as the Update times in the OPC Server and DDE Server configurations depend on it.

An example would be the following: when creating a new Tag, ScanClass is enabled to select one of its options. The Scan Class Configuration window is also observed, where we will previously specify the time that interests us.
