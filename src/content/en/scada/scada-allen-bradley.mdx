Articles about RSView32 and FactoryTalk View SE.

**Rockwell Automation** offers two generations of SCADA systems: **RSView32** (V7.60, legacy but still present in many plants) and **FactoryTalk View SE** (Site Edition, the current platform for plant and enterprise-level supervision).

**RSView32** was a classic SCADA with centralized architecture, tag system, configurable communication channels and DDE/OPC capability. **FactoryTalk View SE** expands this with client/server architecture, FactoryTalk Directory, integrated RSLinx Enterprise, database-based alarm system (FactoryTalk Alarm & Events), Data Logs in SQL Server, and VBA programming for advanced automation.

**FactoryTalk Historian** (based on OSIsoft PI) complements the ecosystem with efficient process data storage, FTLD interfaces and analysis tools. In this section you will find comprehensive configuration guides, VBA scripting, ActiveX controls, security and communications.
