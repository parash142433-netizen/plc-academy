Wonderware AVEVA SCADA: Intouch, System Platform, ArchestrA, Historian

**Wonderware** (now **AVEVA**) is one of the most recognized names in the SCADA world. Its flagship product, **Intouch**, was one of the first Windows-based SCADAs and remains an industry reference alongside the **System Platform (ArchestrA)** platform.

The Wonderware System Platform suite includes **Intouch HMI & OMI**, **Application Server** (Galaxy Repository, IDE, ArchestrA), **Historian Server & Client** and the **Integration Objects** (DAServer, IOServer, OI Gateway). It supports StandAlone and distributed architectures with multiple servers and clients.

In this section we cover Intouch configurations (OPC/DDE communications, databases, ActiveX, HTML5 widgets, alarms, historians), System Platform ArchestrA (galaxies, distributed applications, .Net controls, SQLDataGrid), Historian Server/Client, Information Server and the embedded version Intouch Machine Edition (InTouch Edge HMI).

## Wonderware System Platform

When we talk about Wonderware System Platform, we refer to the Wonderware suite that includes:

*   Intouch HMI & Operation Management Interface (OMI)
*   Application Server (Galaxy Repository & IDE & Common Services)
*   Historian Server & Historian Client
*   Integration Objects (Device Integration IOServer)

Within the architectures, we can find what is called StandAlone (everything included in a single PC/Server) or a Distributed Architecture (Server farm and PCs where each one fulfills its role).
