Siemens WinCC SCADA: WinCC Unified, WinCC Classic V7, WinCC RT Professional, TIA Portal

**Siemens WinCC** is one of the most widely deployed SCADA systems in the industry. Its evolution spans from WinCC V3 (1990s) to the current **WinCC Unified** platform based on web technologies (HTML5, JavaScript, SVG), through **WinCC V7/V8** classic and **WinCC RT Professional** integrated in TIA Portal.

WinCC Classic (V7.x/V8.x) is an open-architecture SCADA supporting single-station, multi-station, client/server, WebNavigator, WebUX and DataMonitor projects. Programming is done in VBScript and ANSI C, with powerful graphic editors, alarm systems, data archiving and user administration (Simatic Logon, Active Directory).

**WinCC RT Professional** is part of TIA Portal and allows designing the SCADA alongside the PLC in a single project. **WinCC Unified** is the future platform: based on web standards, it supports JavaScript scripting, custom controls, and is the native platform for the Unified Comfort Panels.

We also cover the **Process Management AddOns** (PM-Quality, PM-Analyze, PM-Control) for quality control and process analysis in WinCC.
