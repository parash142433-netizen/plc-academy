# WinCC (AS Symbols)

Jose Manuel Luque 09 Feb, 2019

WinCC (AS Symbols) TIA Portal

**WinCC (AS Symbols)**

How can I create variables in WinCC with symbolic addressing from a S7-1200?

When we have created a link with a S7-1200/1500, we have the option to read directly from the CPU. For this, we use the function Read from AS.

![](./assets/images/wincc-as-symbols/WinCC75-000067.png)

However, we encounter the inconvenience that this function only works when Runtime is active.

![](./assets/images/wincc-as-symbols/WinCC75-000068.png)

Once in Runtime, we can execute it and read directly. When we use this function, there are two new tabs AS structures | AS Symbols. To switch the view, we can use the button that is enabled, where the cursor is in the following image.

![](./assets/images/wincc-as-symbols/WinCC75-000071.png)

Here, the following image illustrates the four available tabs.

![](./assets/images/wincc-as-symbols/WinCC75-000072.png)

If we now create a structure in the PLC and a DB Motors, once transferred to the PLC, if we run the function Read from AS again, it automatically loads all the new changes.

![](./assets/images/wincc-as-symbols/WinCC75-000073.png)
