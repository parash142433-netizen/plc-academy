# Backup & Restore WinCC Project Online

Jose Manuel Luque 12 Nov, 2015

Backup project WinCC Online

**Backup & Restore WinCC Project Online  
**

This time, I am not going to present any tutorial or article, but a small application dedicated to my friend Jorge Benito and Mariano, with which we will be able to create a backup of our project while it is open or in Runtime.

It is a Beta version, which has already been tested with several projects and the result has been satisfactory, both with projects using WinCC V7.0 and V7.2, although it should also work with version V7.3. IMPORTANT: In this first version, the TagLogging and AlarmLogging Databases are not included.

Here are some screenshots of the interface and the procedure to follow.

![](./assets/images/wincc-backup-winccruntime/BackupWinCCRuntime_00.png)

Very intuitive and easy to use, select the WinCC project in Runtime and the directory where the Backup will be saved, execute and wait a few seconds or minutes, depending on the size of the Project.

![](./assets/images/wincc-backup-winccruntime/BackupWinCCRuntime_01.png) ![](./assets/images/wincc-backup-winccruntime/BackupWinCCRuntime_02.png)

And here is a demonstration video, although everything runs on the same PC, the goal is to restore it on a different machine or simply to have a Backup of it and later restore it wherever we need...
