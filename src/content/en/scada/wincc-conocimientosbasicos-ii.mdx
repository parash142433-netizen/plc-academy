Jose Manuel Luque

**Basic Knowledge you should know about WinCC  
Open WinCC without a Project.  
**

Basic concepts you should know about WinCC, and to continue with the practices I have started, today we will see the following situation.

Every time we start WinCC, especially on our engineering station, the last project we were working on opens. If we want WinCC to start without any project selected, we need to do the following:

We click the WinCC icon and immediately press the Shift key and keep it pressed until WinCC has started. From that moment on, we can open the project we are interested in, create a new one, etc...

![](./assets/images/wincc-conocimientosbasicos-ii/shift.jpg)

You may already know these concepts, but there is always someone who joins this field, and I think it can be helpful to them :-)
