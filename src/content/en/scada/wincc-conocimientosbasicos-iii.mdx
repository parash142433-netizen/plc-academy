Jose Manuel Luque

WinCC Simatic WinCC Scada WinCC

**Basic Knowledge You Should Know About WinCC  
Reset WinCC  
**

What is the correct procedure to close - restart WinCC when it has frozen?

When we install WinCC, several scripts are installed by default, and one of them is the one we are interested in, located at C:/Program Files/Siemens/WinCC/bin or you can find it by going to Start -> Search Reset\_WinCC.vbs

![](./assets/images/wincc-conocimientosbasicos-iii/reset_wincc_2.png) ![](./assets/images/wincc-conocimientosbasicos-iii/reset_wincc.png)

If not, you can use the application CCCleaner.exe

Or via command line CCCleaner.exe -terminate

After that, you can restart WinCC and that's it :-)

You probably already know these concepts, but there is always someone who joins this world and I think it can be helpful for them :-)
