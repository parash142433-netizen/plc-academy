# WinCC Login/Logout with VBScript

Jose Manuel Luque

WinCC VBScript

**WinCC Login/Logout with VBScript**

Today we will see an example of the theory from a previous practice.

I have created a library that allows logging in and logging out, as well as other user management functions from VBScript. In case you didn't know, in WinCC up to the current version V7.4, you can only log in and log out and perform other functions with C code. But what if for some reason you want to do it from VBScript? The following video shows how it is possible. For better visualization, change the resolution.
