# WinCC Stand-Alone Project

Jose Manuel Luque

WinCC WinCC Stand-Alone

**WinCC Stand-Alone Project**

![](./assets/images/wincc-monopuesto/vba-logo.png) ![](./assets/images/wincc-monopuesto/vba-logo.png) ![](/user_images/vba-logo.png) ![](/user_images/vba-logo.png)

The following animation shows the most typical architecture where the WinCC project has been created as stand-alone; all events of TagLogging, AlarmLogging, and UserRegister are recorded on the same server if configured.

It will also be the Web Server if the WebNavigator has been configured.

                        [![Get Adobe Flash Player](./assets/images/wincc-monopuesto/get_flash_player.gif)](http://www.adobe.com/go/getflash)

The following image is the main view after creating a project of this type; if we compare it with a Multi-User project, we will not see any apparent difference. The difference is evident when adding clients.

In this type of project, no further configuration is needed. If you are interested in seeing the configuration of a [Multi-User project](#/a/en%2Fwincc-multipuesto) or [Client](#/a/en%2Fwincc-cliente)
