# WinCC - No access points found

Jose Manuel Luque 05 Feb, 2019

WinCC - No access points found

**WinCC - No access points found**

I take this opportunity to respond to a question from a student who is doing an internship with WinCC. When he wanted to connect to PLCSim, no access points were available, as shown in the image.

![](./assets/images/wincc-tagmanagement/WinCC75-000004.png)

The solution is very simple, and the reason is that no communication interface is configured.

We go to Control Panel and Set PG/PC Interface

![](./assets/images/wincc-tagmanagement/WinCC75-000005.png)

We select our network card that we will use for communications with the PLC(s) and confirm.

![](./assets/images/wincc-tagmanagement/WinCC75-000006.png)

Problem solved, we can now select S7ONLINE.

![](./assets/images/wincc-tagmanagement/WinCC75-000007.png)
