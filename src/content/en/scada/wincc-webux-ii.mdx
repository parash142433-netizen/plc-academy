# WinCC WebUX

Jose Manuel Luque 06 Feb, 2019

WinCC WebUX Autologin

**WinCC WebUX**

Starting from WinCC version 7.4, the WebUX Service configuration wizard has been updated; the first version was released with [WinCC 7.3](#/a/en%2Fwincc-webux-ii)

![](./assets/images/wincc-webux-ii/WinCC75-000057.png)

In the initial version, it was necessary to create the certificate; with the new wizard, we can now create the certificate directly.

![](./assets/images/wincc-webux-ii/WinCC75-000058.png)

A new feature in version 7.5 is the ability to create auto login for users with Monitor or Operator permissions.

![](./assets/images/wincc-webux-ii/WinCC75-000059.png)

And we finish the wizard.

![](./assets/images/wincc-webux-ii/WinCC75-000064.png)

We can run the wizard again, and its directory is as follows, where the application and the XML configuration file generated by the wizard are located.

![](./assets/images/wincc-webux-ii/WinCC75-000063.png)

And finally, we are going to test this new functionality. We log in with our user, which must be enabled for the WebUX service and have Web Access permissions.

![](./assets/images/wincc-webux-ii/WinCC75-000065.png)

Siemens notes that Windows 10 limits the number of connections; the maximum is 10 sessions or connections.
