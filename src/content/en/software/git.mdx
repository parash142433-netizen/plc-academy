# Version Control — Git & GitHub

Version control and collaborative workflow applied to industrial automation projects.

**Git** is the world's most widely used version control system. Combined with **GitHub**, it allows managing PLC/SCADA project code with the same rigour as professional software development: change history, working branches, code review and team collaboration.
